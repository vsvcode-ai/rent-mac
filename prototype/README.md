# 南洋桌面 · 高保真原型

视觉规范：Linear 体系（来自 getdesign.md）+「墨白 Ink」配色，完整规范见项目根目录 `../DESIGN.md`（开头注明了当前配色与中文本地化调整）。配色方案对比见 `palettes.html`。

纯静态 HTML / CSS / JS，无需构建，无需联网。数据存在浏览器 localStorage，三个端共用一份，所以可以点着走完整条业务链路。

## 怎么打开
- 直接双击 `index.html`，或在本目录运行 `python3 -m http.server 8000` 后访问 http://localhost:8000
- 每个页面左下角有「原型演示」浮条：一键在 前台 / 用户后台 / 管理后台 之间切换，或「重置数据」

## 页面
| 文件 | 内容 |
|---|---|
| `index.html` | 首页：标题逐行升起 + 终端逐行打出的产品截图、规格跑马灯、卖点、使用场景、机柜状态点阵、反色价格色带、价格对比、套餐选择、四步流程、FAQ、页脚大字标 |
| `auth.html` | 登录 / 注册（邮箱 + 验证码 + 密码，任填即可） |
| `order.html` | 确认订单（联系方式、条款勾选） |
| `pay.html?no=` | 订单详情 / 去闲鱼付款（订单号复制、二维码、回填闲鱼订单号、进度时间线、开通倒计时），按订单状态变化 |
| `account.html` | 用户后台：概览 / 订单 / 设备（UU 远程凭证默认隐藏）/ 续费 / 工单 / 设置 |
| `help.html` | 帮助中心：UU 远程连接教程（Mac / Windows / iOS / 安卓）+ FAQ |
| `refund.html` | 退款政策 + 退款金额计算器 |
| `admin.html` | 管理后台：看板 / 订单 / 开通队列 / 机器台账（200 台）/ 回收队列 / 工单 / 设置与权限 |

## 建议的演示路线（约 3 分钟）
1. 首页选「半年付 × 2 台」→ 立即租用 → 登录（点「一键填入演示账号」）
2. 确认订单：填微信、勾选条款 → 提交 → 付款页复制订单号，填任意 10 位以上数字作为闲鱼订单号 → 提交核对
3. 打开「管理后台 → 订单」：找到刚才的订单 →「核对收款」→ 勾选两项 → 确认收款（试试把金额改错）
4. 「开通队列」→「分配开通」→ 勾选检查项 → 完成开通
5. 回到「用户后台 → 我的设备」：看到新机器，点「显示」查看 UU 凭证；点「续费」生成续费单
6. 管理后台确认续费收款 → 到期时间自动延长；「回收队列」演示机器回收

## 原型里是假的部分
闲鱼商品链接/二维码、客服微信、验证码、邮件与站内通知、价格对比里的国际云 Mac 价格、审计日志，都是占位演示数据。

## 品牌与素材
所有图形（Logo、产品界面截图、二维码、教程示意图）均为 CSS/SVG 自绘，未使用任何竞品或 Linear 的品牌素材。
