“固定 IP”听起来平平无奇，但对不少业务是刚需。南洋桌面的每台 Mac mini 都配一条独立宽带，出口地址在租期内保持不变，宽带费用已包含在租金里。

## 适合的场景

### 第三方 API 的 IP 白名单

很多支付、云、数据类服务要求你把调用方的 IP 加进白名单。办公室或家里的宽带地址会变，一台固定出口的机器就是一个稳定的“调用方”：把它的 IP 提交给对方，之后所有请求都从这台机器发出即可。

### 稳定的登录环境

不少平台会根据登录地点和设备做风控，地址频繁变化会触发额外验证。把需要长期保持登录的后台工具、自动化任务放在同一台固定出口的机器上，登录状态会稳定得多。

### 面向特定地区的测试

做出海产品时，经常需要从目标地区的网络访问自己的服务，检查加载速度、定价展示、合规弹窗等。一台位于马来西亚、延迟对东南亚友好的机器，可以作为稳定的测试观察点。

### 跨境业务的日常运营

需要在海外网络环境下操作的运营工作——查看各地区的广告展示、管理海外店铺后台、处理海外平台的客服消息——放在固定的机器上，比反复切换网络环境省心。请确保你的操作符合所在平台的规则。

### 接收回调与长期服务

CI 的构建机、接收 webhook 的小服务、长期运行的脚本，都需要一台一直在线、地址不变的机器。

## 不允许的用法

固定 IP 的价值建立在它的信誉之上，所以以下用途不被允许：

- 把机器当作公共代理、VPN 或流量中转，或者把 IP 转租、转售；
- 发送垃圾邮件、批量注册、刷量；
- 扫描、攻击或任何违法用途。

完整规则见[可接受使用政策](/aup)。违规会被停机且不退款，因为一个用户的违规会影响所有人使用的 IP 信誉。
