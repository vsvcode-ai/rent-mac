AI 编程工具的一次任务经常要跑几十分钟到几个小时。放在笔记本上，合盖、休眠、断网都会打断它；放在一台一直开着的远程 Mac 上，这些问题就没了。下面是一套实际可用的做法。

## 先把机器设成“不睡觉”

远程机器一旦休眠，连接就断了。第一次登录后，在终端里执行：

```
sudo pmset -a sleep 0 displaysleep 0 disksleep 0
sudo pmset -a autorestart 1
```

第二条让机器断电恢复后自动开机。如果只想让某一个任务期间不休眠，可以用 `caffeinate`：

```
caffeinate -dimsu -w <进程号>
```

## 用 tmux 让会话常驻

不要直接在 UU 远程的终端窗口里跑长任务，窗口一关或者连接一断，前台进程就可能跟着结束。用 tmux 把会话托管起来：

```
brew install tmux
tmux new -s claude
# 在里面启动你的任务；按 Ctrl-b 再按 d 脱离
tmux attach -t claude   # 下次回来接着看
```

这样无论你从电脑还是手机连进来，看到的都是同一个正在运行的会话。

## 用手机看进度

UU 远程支持 iPhone 和安卓。离开电脑后，打开手机连上机器，`tmux attach` 就能看到任务跑到哪了，需要你确认的地方也可以直接在手机上回复。

## 几个让长任务更省心的习惯

- **用 git 分支隔离**：让工具在单独的分支或 `git worktree` 里改代码，出了问题直接丢弃分支。
- **小步提交**：任务要求它每完成一个子任务就提交一次，进度不会因为中断而丢失。
- **限定权限范围**：长时间无人值守时，只授予它需要的目录和命令，不要给不必要的权限。
- **定期备份**：机器到期会被回收并抹盘，重要的项目推送到你自己的远程仓库。

## 为什么用独立固定 IP

很多服务会根据登录地点做风控。机器的出口 IP 固定，登录状态和授权记录会更稳定，不会因为网络地址漂移而反复要求验证。南洋桌面每台机器配独立固定 IP，宽带已包含在租金里。
